# IPC-7351 Package Code Mapping

Maps IPC-7351 footprint names to manufacturer package codes.
All listed compatible package codes has been verified as compatible.

| IPC Footprint           | Common Name       | Source Code      | Compatible Codes |
|-------------------------|-------------------|------------------|------------------|
| SOIC127P790X216-8N      | SOIC-8 Wide Body  | Winbond/SN       |                  |
| SOT65P210X110-5N        | SOT-353-5/SC-70-5 | TI/DCK           |                  |
| SOT95P280X120-3N        | SOT-23-3          | Torex/SOT-23     | Vishay/SOT-23 *1 |
| SOT95P280X145-6N        | SOT-23-6          | ST/SOT23-6L      |                  |
| SOP254P700X220-4N       | SO-4/SOP-4        | Toshiba/11-4M1S  |                  |
| QFP80P1200X1200X120-44N | QFP-44            | Microchip/TQFP44 |                  |

## Notes

1. Vishay SOT-23 is slighly lower (1.12mm max) and has shorter lead span than SOT95P280X120-3N. However, recommended minimum pads fits within SOT95P280X120-3N pads.
